# RQ5「猜AI」盲测问卷结果分析指导

> 配套文档：`RQ5_猜AI盲测调查问卷设计.md`。本文档说明该问卷回收的原始数据应如何清洗、计算哪些统计量、如何与检测器/embedding 结果交叉验证，以及如何把结果写入论文的 Results/Limitations。依据来源：`StoryScope_研究方案与论文撰写草稿.md` 第 88-99 行（2.5/2.6节人工评估协议与通用评估控制）、第 179-194 行（RQ5设计）、第192-194行（3.6节多重比较）。

## 0. 分析前提：数据结构

每份问卷回收后，应整理成如下"长表"（每行 = 一个标注者对一组三元组中一段文本的一次判断）：

| 字段 | 说明 |
|---|---|
| rater_id | 标注者匿名编号 |
| group_id | 三元组编号（1-N） |
| label | 该组内的呈现编号 A/B/C |
| true_condition | 密封映射揭晓后的真实条件（human / ai_draft / ai_revised） |
| best_pick | 该标注者在Q[i]-1中认为"最可能人类"选的字母 |
| worst_pick | 该标注者认为"最可能AI"选的字母 |
| likert_score | Q[i]-2 对该 label 的1-5分打分 |
| confidence | Q[i]-3 整体置信度 |
| rationale_text | Q[i]-4 开放作答原文 |
| attention_check_pass | 该组若含注意力检查题，是否通过 |
| rater_informed | S3 是否为知情被试 |

**关键操作**：`true_condition` 必须是在标注者提交问卷**之后**，由研究者读取密封映射文件填入的，绝不能在标注阶段对标注者可见，也不能让参与制表的人在标注仍在进行时接触映射（呼应 pilot 中"盲评判断书写与揭晓映射时间严格分离"的记录方式）。

---

## 1. 数据质量控制（在做任何实质分析前必须先执行）

1. **注意力检查过滤**：剔除 `attention_check_pass = 否` 的标注者的**全部**数据（不是只删该组），并在论文中报告剔除比例。
2. **完成率检查**：剔除完成组数低于预设阈值（如低于总组数80%）的标注者记录，报告剔除人数。
3. **异常作答检查**：检查 `rationale_text` 是否为无意义重复文本（如复制粘贴同一句话应付所有组），若发现应整条剔除并记录。
4. **样本量报告**：清洗后报告最终有效标注者人数、有效组数、总有效判断槽位数，作为 Results 开头的样本量声明（对照 pilot 阶段 n=1 的局限，这里应明确达到方案要求的 20-30 组 × ≥2 名标注者规模）。

---

## 2. 核心指标计算

### 2.1 猜AI准确率（对应pilot中的"3/3"提升为正式统计量）

- 对每个标注者、每组，判断 `best_pick` 对应的 `true_condition` 是否等于 human，`worst_pick` 是否落在 ai_draft 或 ai_revised 之一。
- 定义 **单槽位准确率**：所有"最可能人类"判断中，命中真实人类文本的比例；类似地定义"最可能AI"判断的命中率。
- 报告总体准确率及其 95% 置信区间（可用二项分布 Wilson 置信区间，因为判断是二元命中/未命中的重复观测）。
- **基线对比**：三选一盲猜的随机基线是 33.3%，报告的准确率应与该基线做单样本比例检验（如二项检验），若显著高于随机基线，才能支持"人类读者能够识别AI文本"的结论；若接近或不显著高于随机基线，则支持"AI生成流水线已缩小可分性gap"的核心论点。

### 2.2 分组分析：ai_draft vs ai_revised 的被误认率

- 分别统计 `true_condition = ai_draft` 与 `true_condition = ai_revised` 被标注者判断为"最可能人类"（即被误认为人类）的比例。
- 核心对比：**ai_revised 被误认为人类的比例，是否显著高于 ai_draft**？如果是，说明 revise 流程确实提升了"骗过人类"的能力，这是 RQ5 与 RQ2（修订轮次）联动的关键证据链。
- 用配对设计做统计检验（因为同一组三元组内 ai_draft 与 ai_revised 是被同一批标注者比较的，不是独立样本）：可用 McNemar 检验（二元命中/未命中的配对比较）或混合效应逻辑回归（把 rater_id、group_id 作为随机效应，true_condition 作为固定效应的预测变量，控制标注者个体差异和三元组题材差异）。

### 2.3 连续量表分析（Likert 1-5分）

- 对 `likert_score`（"由人类创作的可能性"打分）按 `true_condition` 分组，计算均值、标准差，画箱线图或小提琴图三组对比。
- 用混合效应线性回归（同样把 rater、group 作为随机效应）检验三组均值差异是否显著，报告效应量（如 Cohen's d 或标准化回归系数）而不只是 p 值。
- 这一步的产出直接对应方案第190行要求的"检测器置信度随处理阶段的漂移"人类读者侧版本——即人类读者主观打分是否也呈现同样的漂移方向。

### 2.4 标注者间一致性（对应2.5节要求）

- 用 `best_pick`/`worst_pick` 的名义分类数据计算 **Cohen's Kappa**（若恰好2名标注者）或 **Krippendorff's alpha**（若标注者数量>2或存在缺失值），报告整体一致性及分条件（human/ai_draft/ai_revised）的一致性。
- 若 Kappa < 0.4（方案明确的阈值），必须在论文 Limitations 中声明并降低对该部分结论的置信度表述，不能把低一致性的数据当作可靠证据直接使用。
- 同时报告知情被试（S3=是）与非知情被试的判断是否存在系统差异（如分别计算两组准确率并做比较），若存在差异应在方法论中讨论是否需要剔除知情被试数据重新分析。

### 2.5 judge-human 一致性（LLM-judge 偏差校准）

- 用同一批三元组材料，让独立 judge 模型（方案要求与drafter/reviser不重叠的模型，如o系列）执行相同的"猜AI"任务，得到 judge 侧的 best_pick/likert_score。
- 计算 judge 与人工标注者判断之间的一致率/Spearman 相关，作为 LLM-as-judge 可信度的量化依据，写入方法论章节。

---

## 3. 与检测器/embedding 结果的交叉验证

1. 将每组三元组的检测器连续 AI 概率、embedding 可分度指标，与该组的人工平均 `likert_score`、误认率对齐成同一张表（按 group_id 合并）。
2. 计算人工判断与检测器概率之间的相关系数（Pearson/Spearman），检验"人类读者的直觉判断"与"机器检测器的量化判断"是否指向同一方向。
3. 若两者高度一致，说明检测器概率可以作为人工评估的低成本代理，用于后续更大规模的批次（如贯穿RQ2各修订轮次）；若两者背离（如检测器认为某段AI概率很低，但人工读者普遍认为像AI），需在Discussion中讨论这种背离本身的意义——可能提示检测器捕捉的信号与人类可感知的"AI味"并不完全重合。
4. 这一步呼应 pilot 阶段的观察：`RQ5_pilot_summary.md` 中统计代理距离与AI套话密度两个信号方向一致，但都只是"AI模拟AI"的自我参照；正式实验中这里换成真实检测器概率与真实人工判断的交叉验证，才真正具备解释力。

---

## 4. 多重比较与效应量报告规范（对应3.6节）

- RQ5 的多组统计检验（准确率vs随机基线、ai_draft vs ai_revised误认率、三组Likert均值差异、judge-human一致性）如果在同一篇论文中与RQ1-4的检验一起报告，需要做 Benjamini-Hochberg FDR 校正，或至少在Discussion中明确声明未校正及其风险。
- 所有显著性结果都应同时报告效应量（Cohen's d、比例差、相关系数）与置信区间，不能只报告p值，避免"小样本下p<0.05但效应量微小"被过度解读。
- 若样本量（组数/标注者数）未达到方案要求的规模（20-30组×≥2人），必须在Limitations中明确样本量不足对统计功效的影响，措辞应为"描述性趋势"而非"证实性结论"。

---

## 5. 结果呈现建议（写入论文 Results 章节的具体形式）

1. **主图**：人机可分性gap轨迹图——横轴为文本来源（human / ai_draft / ai_revised），纵轴同时叠加两条线：(a) 检测器连续AI概率均值±CI；(b) 人工判断"被认为是人类"的比例或Likert均值±CI。两条线方向一致最有说服力。
2. **主表**：准确率表（总体、分条件、95%CI、vs随机基线的检验结果）+ 一致性表（Kappa/alpha、judge-human一致性）。
3. **附录**：开放题 `rationale_text` 的主题编码结果（可用简单的关键词/主题分类，如"依据对话标签""依据心理旁白密度""依据收尾处理"等，统计各主题出现频率），为讨论"人类读者依据什么线索识别AI文本"提供质性证据，可与pilot中agent自述的判断依据（对话标签单一度、句式重复度、心理旁白密度等）做对比，讨论人类评委和AI评委关注的线索是否重合。

## 6. 与 pilot 结果的对照清单（确保正式分析没有遗漏 pilot 暴露的问题）

| pilot 阶段暴露的问题 | 正式分析中的对应处理 |
|---|---|
| 长度混淆（ai_draft明显更短） | 在混合效应回归中把文本长度（字数）作为协变量控制，或在三元组抽取阶段就控制长度接近 |
| n=1，无法计算显著性 | 正式要求20-30组，计算置信区间与显著性检验 |
| 评委是AI自评，非独立人类 | 正式使用真实招募的≥2名人类标注者，报告招募方式与资格审核过程 |
| human_simulated本身是AI模拟 | 正式使用StoryScope真实人类语料替换，问卷设计和分析流程不变，仅替换素材来源 |
| 只有归类判断，没有连续量表 | 正式问卷增加Q[i]-2的5点量表，支持与检测器概率的相关分析而非仅命中率 |
