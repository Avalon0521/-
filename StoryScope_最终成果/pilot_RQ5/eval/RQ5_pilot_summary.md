# RQ5 Pilot 人机可分性 gap 统计代理观察与盲测流程验证（人工模拟人类文本代替真实StoryScope语料、手工统计特征代理代替真实检测器、单agent自评代替真实人工盲测评委）

> 本标题中的三处“代替”是本次pilot最重要的诚实性声明，贯穿全文：
> 1. **人工模拟人类文本代替真实StoryScope语料**——`human_simulated/` 下的文本是本AI在“假设人类作者会怎么写这个场景”的设定下自行撰写的替代文本，**不是**从 StoryScope 10,272 部人类小说语料中抽取的真实人类写作片段，本质上仍是AI生成内容。
> 2. **手工统计特征代理代替真实StoryScope 304类检测器**——本pilot没有调用、也没有复现 StoryScope 检测器，所有“AI-ness”数字都来自纯标准库（`re`/`collections`/`math`）计算的表层文本统计特征距离与几个手工列出的“AI套话”短语密度。
> 3. **单agent自评代替真实人工盲测评委**——“猜AI”盲测环节由本AI在人为模拟的“不知道映射答案”视角下独立完成判断，不是招募的真实第三方人类评委，样本量 n=1。
>
> 以上任何一处替代都与 RQ5 正式方案要求的组件（真实人类语料、真实检测器API、真实人工评委、更大样本量）存在本质差异，本文档中的一切数字结论**只能视为“pilot流程是否可执行”的验证，不能作为“AI生成内容能否骗过真实读者/检测器”这一核心研究问题的证据**。

## 目的

验证 RQ5 实验流程（人类原文 / AI原始草稿 / AI修订稿三元组 → 统一“AI-ness”探针打分 → 盲测“猜AI”任务 → 人机可分性 gap 方向性观察）与指标体系在最小规模（1组三元组、每条件2章）下是否可执行、可测，并诚实评估这次 pilot 在多大程度上填补了 RQ3 pilot 总结中指出的“缺少人类语料基线对照”这一最大解释力缺口。

## 方法说明：统计特征代理指标与盲测协议的选择理由与局限

### 统计特征代理（“AI-ness探针”代理）

延续 RQ3 pilot 的方法，选用可从纯文本直接计算、不依赖分词器/外部NLP库的特征：字符级distinct ratio（`char_ttr`）、字符bigram distinct ratio（`bigram_ttr`，近似词级多样性）、平均句长、标点密度（逗号/句号/破折号/引号/省略号，每100字）、25个固定虚词的每100字频率、19个高频叙事动词的每100字频率。所有特征展平为定长向量后z-score标准化，计算两两欧氏距离（主要“可分性”代理）与余弦相似度（辅助参照）。

本次新增第二个独立的、更直接的“AI-ness”表层信号：19个常见中文AI小说套话短语（“仿佛/似乎/不禁/缓缓/不由得/悄然/静静地/轻轻地/缓缓地/微微/隐隐/渐渐/不知不觉/若有所思/心中一动/若隐若现/一时之间/心头/眼神复杂”）的每100字总密度，凭经验列出、未经任何统计验证，仅作为交叉参照，未纳入欧氏距离的特征向量（避免两个代理信号互相污染）。

**必须明确的局限（这不是真实检测器/embedding的替代品）**：
- 这是维度极低（8个句法/标点特征 + 25个虚词 + 19个动词，约52维）的手工表层统计量，且很多维度在777~1088字的短文本中计数极小、噪声很大，完全无法捕捉语义、叙事视角、心理刻画深度等更深层的风格/AI-ness信号。真实StoryScope 304类检测器（很可能基于训练过的分类器/embedding）能捕捉的信号远比这些统计量丰富。
- 19个“AI套话”短语是本AI凭经验主观列出的清单，**没有经过任何独立验证**（例如没有在大规模人类语料和AI语料上验证这些短语确实是可靠的判别特征），密度高低只是一种极简单的观察维度，不代表真实的判别力。
- **文本长度是强混杂变量**：human_simulated（1065字）、ai_draft（777字）、ai_revised（1088字）三者字数差异达40%，而句长、标点密度等特征对长度敏感。值得特别注意的是：**ai_revised（1088字）与human_simulated（1065字）字数几乎相同（仅差23字），而ai_draft（777字）与human_simulated相差288字（约27%）**——这意味着下文报告的“ai_revised统计上更接近human_simulated”这一方向性观察，有相当大的可能性主要是被“修订后文本长度恰好更接近本次人类模拟文本长度”这一混杂因素驱动，而不是revise真正让文本风格更像人类写作。本pilot样本量（n=1组三元组）完全无法把“长度效应”和“风格效应”分离开。
- 样本极小（每条件仅2章合并为1个文档向量），无法计算方差、无法做置信区间或显著性检验，任何距离数字都只是单点观察。

### 盲测“猜AI”协议

由于没有真实第三方人工评委，本次pilot执行了一次“自我盲测”流程：先用脚本生成密封的随机映射（A/B/C对应哪个条件），再生成对应的匿名文本文件，本AI在**未查看映射文件**的情况下，仅依据三段匿名文本本身的内容特征给出独立判断，判断记录完成后才读取映射文件揭晓答案并计算准确率（完整记录见 `blind_guess_record.md`，判断部分与揭晓部分在时间上严格分离，判断内容未做事后修改）。

**必须明确的局限**：这是同一个agent（本AI自己）在缺少真人评委的情况下扮演评委角色产生的替代数据，不是真实独立人类读者的判断；本agent可能比真实人类读者更容易/更不容易识别出自己模型输出的行文特征（既可能因为对自身生成套路“内部敏感”而更容易猜对，也可能因为无法真正代入人类读者的阅读直觉而产生系统性偏差），这两种可能性本pilot都无法排除；样本量 n=1（一组三元组，3个判断槽位），**无法计算统计显著性**，只能验证“打乱编号→独立盲评→揭晓映射→计算准确率”这条流程本身是否可执行、是否记录完整。

## 关键发现

1. **两个独立的统计代理信号（欧氏距离/余弦相似度 与 AI套话密度）方向一致地显示：ai_revised 比 ai_draft 更接近 human_simulated**——这个方向与“修订应该让AI文本更像人类”的直觉假设**一致**，不是反例。但如上文局限中强调的，这个方向性观察很可能主要由**文本长度混淆**驱动：ai_revised（1088字）与human_simulated（1065字）字数几乎相同，而ai_draft（777字）明显更短；句长、标点密度等特征对长度天然敏感。本pilot完全无法把“revise让文本风格更像人类写作”与“revise恰好把文本长度调整到与本次人类模拟文本更接近的区间，从而在统计特征上显得更接近”这两种解释区分开来——这正是需要在正式实验中用更大样本量、并对文本长度做统计控制才能回答的问题。

2. **盲测猜AI 3/3 全部猜对，但这个结果几乎不能说明任何关于“AI能否骗过真实读者”的问题**。首先n=1，其次评委是本AI自己而非独立人类，本agent很可能对自己模型输出的行文套路（尤其是ai_draft中“看了看，又看了看”式重复、对话标签单一使用“说”这类模式）有远超普通人类读者的敏感度，这种敏感度既不代表真实人类读者会做出同样判断，也不代表本AI的判断标准具有可推广性。这个100%准确率**只验证了“打乱编号→盲评→揭晓映射→计算准确率”这条流程本身可以被完整、诚实地执行**，不能作为任何实质性结论。

3. **对 RQ3 pilot 总结中提出的“缺少人类语料基线对照”这一最大解释力缺口的回应：本次pilot几乎没有真正填补这个缺口**。RQ3 pilot 明确指出：“无法回答这三种人工控制风格之间的统计距离，相对于真实作者之间的自然风格差异是大是小”；本次RQ5 pilot引入的“human_simulated”条件表面上提供了一个“人类”参照点，但**这个参照点本身是AI生成的模拟文本，不是真实人类写作**，因此上面测得的“ai_revised更接近human_simulated”这一数字，回答的问题仍然是“AI修订稿在统计特征上更接近另一段AI模拟人类写作的文本”，而**不是**“AI修订稿在统计特征上更接近真实人类作者的自然写作”。这两个问题看似相似，实际上完全不能等价——本AI模拟“人类会怎么写”时，很可能不自觉地代入了自己作为语言模型的写作偏好（用词选择、句式节奏、甚至什么叫“克制”本身都是AI对“人类写作”的想象），这种模拟偏差的方向和幅度未知、无法验证。因此，RQ3指出的缺口在本次pilot后**依然完全存在**，正式实验必须用真实StoryScope人类语料替换`human_simulated`条件才能真正回答这个问题。

## 对方案的具体建议（把本pilot升级到正式RQ5实验需要补齐的清单）

- **真实人类语料抽取**：从 StoryScope 10,272 部人类小说语料中，按题材（都市悬疑）和章节位置（对话/线索推进场景）匹配抽取真实片段，替换本pilot的`human_simulated`条件——这是最优先、最不可替代的一项，没有它，人机可分性gap的所有数字都只是“AI模拟AI”的自我参照。
- **真实检测器接入**：调用或复现StoryScope 304类检测器，替换本pilot的手工统计特征距离与AI套话密度代理——本pilot的代理指标维度极低、特征清单主观，与真实检测器的判别力不可比。
- **真实人工评委招募**：按方案2.5节人工评估协议招募独立第三方评委执行盲测“猜AI”任务，评委人数需达到可计算评委间一致性（inter-rater agreement）和统计功效的规模，替换本pilot的单agent自评。
- **控制文本长度混淆**：正式实验中三元组（人类原文/AI草稿/AI修订稿）应尽量匹配字符数/句数，或在分析阶段将长度作为协变量控制，避免本pilot中观察到的“ai_revised统计上更接近human_simulated”被长度接近这一混杂因素主导而非真实解读为风格趋同。
- **样本量扩大**：正式实验需要多个三元组（覆盖不同题材、不同章节位置），才能计算方差、做置信区间或显著性检验；本pilot n=1完全不足以支撑任何统计推断。
- **贯穿RQ2/RQ3的检测器置信度轨迹**：按方案第187行设计，把真实检测器接入后应同时对RQ2各修订轮次（不只是round0/round3两端点，还有round1/round2中间轮次）打分，观察AI-ness概率的连续漂移轨迹，而不只是本pilot做的两点式（草稿/最终稿）对比。

## 诚实结论

本次pilot验证了RQ5实验流程（三元组构造 → 统计代理特征计算 → 盲测猜AI）在最小规模下可以被完整、诚实地执行：两个独立统计代理信号一致显示ai_revised比ai_draft更接近human_simulated，盲测猜AI流程完整跑通并3/3猜对。

但必须再次强调：**这些数字全部建立在“人类文本本身是AI模拟的、检测器是手工统计特征代理、评委是本AI自己”这三重替代之上**，其中第一重替代（human_simulated并非真实人类语料）使得本pilot事实上**没有**真正回答RQ3指出的“缺少人类语料基线对照”这一核心缺口——它只是把这个缺口从RQ3的“完全没有人类参照”，缩小成了RQ5的“有一个AI假扮的人类参照”，这一步在方法论上仍然是原地踏步，而不是实质进展。“ai_revised统计上更接近human_simulated”这一唯一的方向性发现，本身还高度可能是文本长度巧合导致，而不是revise真正提升了人类相似度。加上盲测n=1、无统计显著性、检测器未真正接入，本次pilot的全部结论都只是**方向性观察与流程验证，不构成任何具有统计效力或可推广性的证据**。正式实验前必须优先补齐“真实人类语料”这一项——它是本pilot留下的最大、且唯一无法用任何代理方案绕过的结构性缺口。
