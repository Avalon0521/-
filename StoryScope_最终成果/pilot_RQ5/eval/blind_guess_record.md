# RQ5 pilot 盲测猜AI记录（诚实性声明见文末）

## 盲测流程说明

1. `make_blind_mapping.py` 随机生成了 A/B/C 到三个条件（human_simulated / ai_draft / ai_revised）的映射，写入密封文件 `blind_mapping_SECRET.json`，运行时刻意未在终端打印映射内容。
2. `make_anonymized_texts.py` 依据该密封映射生成了三份匿名合并文本 `blind_text_A.txt`、`blind_text_B.txt`、`blind_text_C.txt`（每份为 ch1+ch2 拼接），运行时同样未打印映射内容。
3. 本agent（评审角色）随后仅依次阅读 `blind_text_A/B/C.txt` 三个文件本身，在阅读阶段没有主动查看 `blind_mapping_SECRET.json`，基于纯文本内容特征给出下方判断。
4. 判断记录完成后，才读取 `blind_mapping_SECRET.json` 揭晓真实映射并计算准确率（见下方“真实映射与准确率”）。

## 盲评判断（基于文本内容特征，判断时未查看映射文件）

- **文本 C**：对话标签几乎全部使用“说”，句式重复度高（如“看了看，又看了看”“慢慢的”反复出现），描写较扁平、缺少细节修饰，整体呈现“信息传递优先、文学加工较少”的特征。
  判断：**ai_draft（AI原始草稿，未修订）**

- **文本 B**：细节最为丰富，出现多处显式的心理推理说明句（例如对怀表挂坠敲痕工艺的推断“不像机器批量压制”，以及“这种细节她从不会放过，哪怕案子看起来无关紧要”这类对角色习惯的额外旁白式说明），描写密度和解释性明显高于其他两段，呈现“在已有骨架上做了增补打磨”的痕迹，但也略显“过度解释推理过程”。
  判断：**ai_revised（AI经3轮修订后的文本）**

- **文本 A**：叙事节奏自然、克制，没有刻意堆砌感官细节或显式心理旁白，收尾用“周伯的身影立在柜台后面，一动没动”这种留白式处理，整体语言密度和信息量适中，不像是“为解释而写”的段落。
  判断：**human_simulated（人类模拟文本）**

> 诚实性声明：本盲测由同一个agent（本AI）在缺少真实第三方人类评委的情况下，人为模拟“不知道映射答案”的评审视角完成，不是独立人类读者的判断。样本量 n=1（一组三元组），因此只能用来验证“打乱编号 -> 盲评 -> 揭晓映射 -> 计算准确率”这一流程本身是否可执行、是否记录完整，完全不能作为“AI生成内容能否骗过真实人类读者”这一核心研究问题的有效证据。即使本次猜测全部猜对，也不代表AI文本可以骗过真实读者；即使猜错，也不代表AI文本必然能被真实读者识破——单次单人判断没有推广力。
